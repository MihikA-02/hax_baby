# Zoobi — The Universe Color Keeper

Welcome to the Zoobi project.

## Getting Started

To run the development server:

```bash
npm run dev
# or
bun dev
```

## Project Structure
- `src/assets`: Images and visual assets
- `src/components/ui`: UI components
- `src/hooks`: Custom React hooks
- `src/lib`: Utilities and helpers
- `src/routes`: Routes and page views
- `src/test`: Tests and testing configuration
